# Search Agent

Build a LangChain search agent on the `project/search-agent` branch.

## Setup

1. Install dependencies:

   ```bash
   uv sync
   ```

2. Add API keys to `.env`:

   ```bash
   OPENAI_API_KEY=your_openai_key
   TAVILY_API_KEY=your_tavily_key
   ```

3. Run the starter script:

   ```bash
   python main.py
   ```
