# LangChain Course

This repository contains materials for a hands-on course on LangChain, a framework for building applications with large language models (LLMs). The course is designed to introduce core LangChain concepts, provide practical examples, and guide learners through building real-world LLM applications.

## Contents
- examples/: Small, focused code examples demonstrating LangChain primitives (chains, agents, prompts, memory).
- notebooks/: Jupyter notebooks with guided tutorials and exercises.
- docs/: Supplemental documentation and notes for each lesson.

## Goals
- Teach how to design prompts and compose chains.
- Show how to integrate tools, agents, and memory for stateful applications.
- Provide reusable patterns for production-ready LLM apps.

## Getting Started
1. Clone the repo.
2. Create a virtual environment and install dependencies (see requirements.txt).
3. Open notebooks/ or run example scripts to follow along.
